How the calculation works

File sizes are measured in bytes (MB, GB) while connection speeds are measured in bits per second (Mbps). Because there are 8 bits in a byte, the formula is:

Time in seconds = file size in MB × 8 ÷ speed in Mbps

So a 1000 MB file on a 100 Mbps connection takes 1000 × 8 ÷ 100 = 80 seconds. This calculator uses 1 GB = 1024 MB and 1 TB = 1024 GB, the way operating systems report file sizes.

Why real downloads can take longer

  • Shared connection: if other people or devices are streaming or downloading at the same time, your share of the speed is smaller.
  • Server limits: some servers cap how fast they send files, so even a fast connection cannot go quicker.
  • Wi-Fi: the speed your plan offers is not always the speed your device gets over Wi-Fi, especially far from the router.
  • Overhead: a small part of every connection is used by the network itself, so real-world times are usually a few percent longer than the estimate.
Tip: If downloads feel slower than this calculator says they should, run the speed test and compare the measured speed with the speed your plan promises. If there is a big gap, read Why Is My Internet Slow at Night?.

Frequently Asked Questions

What is the difference between MB and Mbps?

MB (megabytes) measures file size; Mbps (megabits per second) measures connection speed. There are 8 megabits in a megabyte, which is why a 100 Mbps connection downloads at most about 12.5 MB per second.

How long does a 1 GB file take on a 100 Mbps connection?

About 1 minute 22 seconds. A gigabyte is 1024 MB, so 1024 × 8 ÷ 100 = 81.9 seconds.

Why does the estimate assume 1 GB = 1024 MB?

Operating systems and most download managers report sizes in binary units, where 1 GB = 1024 MB. Some storage makers use 1000 MB instead, so the real file may be slightly smaller than the label suggests.
